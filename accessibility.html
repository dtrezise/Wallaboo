Site information

Accessibility

Mr Wallaboo Games aims to make this temporary website usable with a keyboard, screen reader, text resizing, high zoom, and reduced-motion preferences.

Current design

  • A skip link moves directly to the main content.
  • Navigation and controls use semantic labels and visible keyboard focus.
  • Content remains visible if animation scripts do not run.
  • Motion is removed when the operating system requests reduced motion.
  • The layout adapts to narrow screens and enlarged text.

Feedback

A public support channel will be added before the company begins taking orders or collecting customer information. Until then, no transaction or account function depends on this site.
